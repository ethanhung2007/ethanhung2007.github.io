SIMT GPU Core

SIMT GPU Streaming Multiprocessor based off of a custom ISA

01The Problem 02The Process 03The Outcome

01The Problem

I wanted to gain a more concrete understanding of how a SIMT architecture works and how parallelism is achieved on such an architecture.

02The Process

Knowing the complexity of modern day GPUs, I had to create a simplfied version of the ISAs with only the essential instructions. After understanding how I would implement the features from a high level understanding, I began building from the bottom up, starting with individual lanes. After the lanes, I built the warps and control logic. After I built each small part of the core, I would verify the basic functionality using Verilator. Lastly, I developed the fetch, decode, and scheduling blocks, finishing my GPU core.

03The Outcome

My GPU was synthesized on an Arty-A7-100T to 18.9K LUTs, 22.8K FFs, and 12 DSPs at 50 MHz. I then wrote 3 simple GPU kernels written in assembly that includes vector add, matrix multiply, and reduction. These GPU kernels would run on my GPU then verified against a golden reference model to ensure accuracy.
